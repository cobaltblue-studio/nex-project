## 에이전트 규칙 (앞으로)

마크·아이콘·팔레트가 **업그레이드되어 바뀌면**:

1. 바뀌기 **직전** 확정본을 여기로 옮긴다.  
   경로 예: `history/YYYY-MM-DD-<short-name>/`
2. **핵심 이미지만** 남긴다 (보통: 앱 아이콘 1장 + 필요 시 워드마크 1장 + 짧은 `NOTE.md`).  
   워드마크 변형·compare HTML·실패 SVG·중간 생성물 전부 쌓지 않는다.
3. 상위 `Brand/icons|logo|palette` 에는 **새 확정본만** 둔다.
4. 파일 **삭제**는 대표 승인 후에만. 히스토리로 **이동**은 OK.
