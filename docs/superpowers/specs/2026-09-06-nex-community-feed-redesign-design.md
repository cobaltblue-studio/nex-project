## 문제 (대표님)

커뮤니티가 너무 어지럽다.  
유튜브·SNS처럼 글 / 댓글 / 좋아요 / 전달 / 피드가 쉬워야 하는데,  
지금은 “이게 커뮤니티인가?”가 안 나온다.

원인: Reddit 포럼 + 트랙 필수 + upvote/하트 섞임 → 숙제 같음.

## 하고 싶은 것 (대표님)

**A+B+C 다.**  
짧게 올리기 + 트랙 자랑 + 토론.

메뉴 세 개로 쪼개지 말고 → **피드 하나**, 글 종류만 다르게.

첫 화면 = **전체 최신**.  
트랙 자랑은 그 안에 **살짝만**.

## 이렇게 가자 (대표님 “가자”)

1. 들어오면 타임라인. 사이드바 카테고리 없음.  
2. 버튼은 **좋아요 · 댓글 · 공유**만.  
3. 글쓰기 = 바로 텍스트 (토크 기본).  
   칩: 토크 / 트랙 자랑 / 토론.  
4. **트랙 필수 아님.**  
   (“필수면 귀찮아서 안 함. 아직 유명하지도 않은데.”)  
5. 텍스트 글 ≈ 트랙 글, 크기 비슷하게.  
6. 예전 글은 안 지우고 피드로 옮김.  
7. 팔로잉·DM·스토리·댓글 통합은 나중에.

### 색 — 박스 안쪽 (대표님)

지금 커뮤니티 박스가 **시커멓다** (`bg-zinc-950` 계열).  
**박스 안쪽은 아이보리로 밝게.**  
바깥(페이지 배경)은 NEX 톤 유지해도 되고,  
글 카드·글쓰기·상세 같은 **내용 박스 안만** 아이보리.  
글자색은 어두운 톤으로 맞춰 읽히게.
